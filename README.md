# Audit critique du cours « Premier cours de finance à HEC Paris »

Audit factuel, critique et documenté du cours « Premier cours de finance à HEC Paris », enseigné par Olivier Bossard.

Ce dépôt analyse chronologiquement les principales affirmations formulées pendant le cours et confronte leur contenu aux sources disponibles, en privilégiant les sources primaires et institutionnelles : banques centrales, organismes internationaux, autorités de marché, institutions publiques, publications académiques et documents officiels.

L'objectif n'est pas de juger le professeur ou de produire une évaluation subjective du cours, mais d'identifier précisément :

- les affirmations factuellement correctes ;
- les affirmations globalement correctes mais nécessitant une précision ;
- les simplifications pédagogiques susceptibles d'induire en erreur ;
- les affirmations inexactes ou trop générales ;
- les anecdotes dont la vérifiabilité est insuffisante ;
- les chiffres nécessitant une date, une définition ou une méthodologie ;
- les distinctions conceptuelles importantes qui disparaissent dans la formulation orale.

Pour chaque point significatif, l'audit cherche à établir la formulation prononcée, son contexte, le verdict, les éléments vérifiables, le problème éventuel, la correction proposée et les sources permettant de contrôler cette correction.

Une attention particulière est portée aux sujets tels que la monnaie, l'or et la monnaie fiduciaire, l'inflation, les marchés financiers, les changes, les actions, les obligations, les produits dérivés, les hedge funds, le trading algorithmique, la vente à découvert, la dette souveraine, les crises financières, les modèles financiers et les performances historiques des marchés.

L'audit distingue explicitement les faits établis, les inférences, les simplifications pédagogiques, les hypothèses et les éléments non vérifiés. Il ne transforme pas une affirmation plausible en fait établi lorsqu'une source suffisamment solide n'a pas été trouvée.

Le dépôt constitue ainsi une documentation de vérification et de contextualisation du cours, destinée à permettre au lecteur de distinguer ce qui relève d'un fait financier établi, d'une approximation pédagogique, d'une interprétation ou d'une affirmation qui nécessite d'être corrigée


## Objet

Ce dépôt contient un audit factuel, pédagogique et chronologique de la
conférence vidéo **« Premier cours de finance à HEC Paris »**, animée
par **Olivier Bossard**, professeur de finance à HEC Paris et ancien
praticien des marchés financiers.

L’objectif n’est **pas** de résumer le cours, mais d’examiner les
affirmations formulées pendant les environ **1 h 26 min 11 s** de la
conférence et de distinguer :

- les faits solides ;
- les simplifications pédagogiques acceptables ;
- les formulations imprécises ou trompeuses ;
- les erreurs factuelles ;
- les affirmations quantitatives qui nécessitent une date ou une
  définition ;
- les anecdotes qui ne peuvent pas être établies à partir de sources
  suffisamment fiables.

Le principe directeur est simple :

> Une intuition pédagogique peut être utile sans être une formulation
> rigoureuse. L’audit cherche précisément à identifier le moment où la
> simplification cesse d’être pédagogique et devient trompeuse.

------------------------------------------------------------------------

## Périmètre et méthode

### Sources examinées

L’audit repose principalement sur :

1.  la transcription de la conférence fournie pour l’analyse ;
2.  les deux passes d’audit chronologique réalisées à partir de cette
    transcription ;
3.  des sources institutionnelles et primaires utilisées pour vérifier
    les points importants.

Les principales sources externes sont notamment :

- Banque des règlements internationaux (**BIS**) ;
- Banque centrale européenne (**BCE**) ;
- Commission européenne ;
- U.S. Securities and Exchange Commission (**SEC**) ;
- Social Security Administration (**SSA**) ;
- U.S. Department of the Treasury ;
- International Monetary Fund (**IMF**) ;
- Japan Exchange Group (**JPX**) ;
- SIFMA ;
- Berkshire Hathaway ;
- Nobel Prize / travaux historiques sur Black-Scholes.

### Échelle de verdict

| Symbole | Signification                                                 |
|---------|---------------------------------------------------------------|
| 🟢      | Correct ou suffisamment exact                                 |
| 🟡      | Globalement correct, mais nécessitant une précision           |
| 🟠      | Simplification devenue trompeuse ou formulation trop générale |
| 🔴      | Erreur factuelle ou affirmation incorrecte                    |
| ⚪      | Anecdote, chiffre ou affirmation insuffisamment vérifiable    |

### Critère de correction

Pour chaque affirmation importante, l’audit cherche à répondre à six
questions :

1.  **Que dit exactement le professeur ?**
2.  **Est-ce factuellement exact ?**
3.  **Quelle nuance ou quel problème faut-il signaler ?**
4.  **Quelle formulation serait pédagogiquement plus rigoureuse ?**
5.  **Quelle source permet de vérifier le point ?**
6.  **Quel niveau de confiance peut-on accorder à la correction ?**

# Synthèse générale

Le cours est **pédagogiquement efficace mais factuellement inégal**.

Olivier Bossard annonce lui-même qu’il présente la finance « très
schématiquement ». Cette précision est importante et explique une partie
des raccourcis.

Le problème apparaît lorsque certaines simplifications sont formulées
comme des règles générales.

Les principales erreurs ou formulations dangereuses concernent :

1.  le billet de **100 milliards** de dollars zimbabwéens ;
2.  l’affirmation selon laquelle les États-Unis n’auraient **pas de
    pension publique de retraite** ;
3.  l’affirmation selon laquelle les **hedge funds ne font pas de
    hedging** ;
4.  la présentation du marché des dérivés comme « valant un quadrillion
    de dollars » sans distinguer **notionnel** et **valeur de marché** ;
5.  la confusion entre **forward** et **futures** dans l’exemple du
    pétrole ;
6.  l’affirmation qu’un particulier ne peut pas vendre à découvert ;
7.  l’idée que les **futures seraient le seul moyen** d’obtenir une
    exposition baissière ;
8.  l’affirmation selon laquelle tous les modèles prédictifs seraient
    fondés sur le passé ;
9.  l’exemple probabiliste du parapluie ;
10. l’affirmation que la finance serait le seul domaine où les modèles
    influencent leur objet ;
11. l’affirmation selon laquelle les meilleurs traders gagnent « 52 % du
    temps » ;
12. l’affirmation que les actions « vont monter » sur 5 ou 10 ans ;
13. l’idée que les actions rapporteraient nécessairement 5 à 10 % par an
    ;
14. plusieurs généralisations sur les taux d’intérêt, la confiance et la
    spéculation ;
15. plusieurs anecdotes personnelles ou professionnelles présentées sans
    source vérifiable.

# Audit chronologique

## 00:00–02:16 — Définition de la monnaie

### « La monnaie sert à compter et à échanger »

**Verdict : 🟢**

La formulation correspond à deux fonctions classiques de la monnaie :
**unité de compte** et **moyen d’échange**.

Il manque cependant la troisième fonction classique : **réserve de
valeur**.

### Formulation recommandée

> **« La monnaie remplit notamment trois fonctions : unité de compte,
> moyen d’échange et réserve de valeur. »**

**Source :** BIS, travaux sur les fonctions de la monnaie.  
**Confiance : élevée.**

------------------------------------------------------------------------

## 02:16–03:22 — Troc et réserve de valeur

### « Au départ, tout ça se faisait directement \[…\] avec du troc »

**Verdict : 🟡**

Le troc est bien une forme historique d’échange, mais l’histoire de
l’apparition de la monnaie est plus complexe que le schéma linéaire :

> troc → problèmes du troc → monnaie.

### Formulation recommandée

> **« Le troc constitue une forme ancienne d’échange direct. L’histoire
> de la monnaie est cependant beaucoup plus complexe que le simple
> passage du troc à la monnaie. »**

------------------------------------------------------------------------

### « Il faut quelque chose qui conserve sa valeur dans le temps »

**Verdict : 🟢/🟡**

Cela correspond à la fonction de réserve de valeur, mais aucune monnaie
ne garantit une conservation parfaite du pouvoir d’achat.

### Formulation recommandée

> **« Une fonction de la monnaie est de servir de réserve de valeur,
> même si son pouvoir d’achat peut diminuer avec l’inflation. »**

------------------------------------------------------------------------

# 03:22–06:15 — Or, valeur intrinsèque et monnaie fiduciaire

## « La première forme de monnaie, ça a été les métaux précieux »

**Verdict : 🔴**

Cette affirmation est trop générale.

Les sociétés ont utilisé des formes monétaires très diverses. Les métaux
précieux ont effectivement joué un rôle monétaire majeur, mais ils ne
constituent pas l’origine unique ou universelle de la monnaie.

### Formulation recommandée

> **« Les métaux précieux, notamment l’or et l’argent, ont joué un rôle
> monétaire majeur dans de nombreuses sociétés, mais ils ne constituent
> pas l’origine unique de la monnaie. »**

------------------------------------------------------------------------

## « Les métaux précieux ont une valeur intrinsèque »

**Verdict : 🟡**

L’or possède des usages non monétaires, notamment industriels et
ornementaux, mais parler de « valeur intrinsèque » comme d’une valeur
objective indépendante du marché est économiquement imprécis.

### Formulation recommandée

> **« L’or possède des usages non monétaires et une valeur marchande
> indépendante de son rôle monétaire ; ces caractéristiques ont
> contribué à son utilisation historique comme monnaie. »**

------------------------------------------------------------------------

## « La valeur intrinsèque \[du billet\] est de zéro »

**Verdict : 🟡**

Comme opposition pédagogique entre monnaie-marchandise et monnaie
fiduciaire, l’idée est compréhensible.

Mais « valeur intrinsèque » n’est pas une mesure économique précise.

### Formulation recommandée

> **« La valeur matérielle du billet est très faible par rapport à sa
> valeur monétaire ; cette dernière repose sur le système monétaire,
> juridique et institutionnel ainsi que sur la confiance dans celui-ci.
> »**

------------------------------------------------------------------------

## « Il est émis par la Banque centrale européenne »

**Verdict : 🟠**

La formulation est juridiquement incomplète.

La BCE et les banques centrales nationales de l’Eurosystème sont
légalement habilitées à émettre les billets en euros ; les banques
centrales nationales les mettent concrètement en circulation.

### Formulation recommandée

> **« Les billets en euros sont juridiquement émis par la BCE et les
> banques centrales nationales ; en pratique, les banques centrales
> nationales les mettent physiquement en circulation. »**

**Source :** BCE.  
**Confiance : très élevée.**

------------------------------------------------------------------------

# 06:27–08:26 — Confiance, Venezuela, Zimbabwe et Bitcoin

## « En 2008, on n’a pu faire confiance à personne »

**Verdict : 🟠**

C’est une formule rhétorique.

La crise financière de 2008 a effectivement entraîné une forte
détérioration de la confiance entre institutions financières, mais cette
phrase ne doit pas être comprise littéralement.

### Formulation recommandée

> **« La crise financière de 2008 a fortement dégradé la confiance entre
> certaines institutions financières et dans certains actifs et
> intermédiaires. »**

------------------------------------------------------------------------

## Venezuela : inflation → perte de confiance → dollar / Bitcoin

**Verdict : 🟡**

Le mécanisme général est plausible, mais la causalité est présentée de
manière trop linéaire.

### Formulation recommandée

> **« Au Venezuela, l’hyperinflation et la crise économique ont
> fortement réduit l’usage du bolivar et favorisé la substitution par
> des monnaies étrangères et d’autres actifs. »**

------------------------------------------------------------------------

## Zimbabwe : « billet de 100 milliards »

**Verdict : 🔴 ERREUR FACTUELLE MAJEURE**

Le billet emblématique était de :

**100 000 milliards de dollars zimbabwéens = 10¹⁴**

et non :

**100 milliards = 10¹¹**.

### Formulation recommandée

> **« Le Zimbabwe a notamment émis un billet de 100 000 milliards de
> dollars zimbabwéens pendant l’hyperinflation de 2008. »**

**Source :** IMF.  
**Confiance : très élevée.**

------------------------------------------------------------------------

## « Cette monnaie, elle n’existe plus »

**Verdict : 🟡**

La monnaie a effectivement cessé d’être la monnaie effectivement
utilisée pendant la dollarisation de 2009, mais l’histoire monétaire du
Zimbabwe ne s’est pas arrêtée là.

### Formulation recommandée

> **« Le dollar zimbabwéen a pratiquement disparu de la circulation lors
> de la dollarisation de 2009, avant différentes réintroductions
> monétaires ultérieures. »**

------------------------------------------------------------------------

## Bitcoin « indépendant des banques centrales »

**Verdict : 🟢/🟡**

Bitcoin ne possède pas de banque centrale émettrice contrôlant le
protocole.

Mais cela ne signifie pas qu’il est indépendant de tout environnement
institutionnel, économique ou réglementaire.

### Formulation recommandée

> **« Bitcoin fonctionne sans banque centrale émettrice ni autorité
> centrale contrôlant directement son registre, même s’il reste soumis à
> son environnement juridique et économique. »**

------------------------------------------------------------------------

# 08:08–09:54 — Confiance, prix et Dōjima

## « Tout est basé sur la confiance »

**Verdict : 🟡**

Bonne intuition pédagogique, mais ce n’est pas une théorie exhaustive de
la finance.

La finance dépend également du risque, de la liquidité, de
l’information, des institutions, des incitations et des contraintes
juridiques.

### Formulation recommandée

> **« La confiance est un élément fondamental de la monnaie et de la
> finance, aux côtés du risque, de la liquidité, de l’information, des
> institutions et des incitations. »**

------------------------------------------------------------------------

## « Le pétrole monte \[…\] parce qu’on n’a pas confiance dans une résolution rapide »

**Verdict : 🟠**

Une crise géopolitique peut effectivement faire monter les prix du
pétrole, mais les prix résultent de nombreux facteurs.

### Formulation recommandée

> **« Une aggravation du risque géopolitique peut faire monter les
> anticipations de prix du pétrole, notamment en raison des risques
> pesant sur l’offre. »**

------------------------------------------------------------------------

## Dōjima : « 1736 »

**Verdict : 🟠**

Le Dōjima Rice Exchange constitue bien un jalon majeur de l’histoire des
marchés à terme.

Mais la date officielle donnée par Japan Exchange Group est **1730**, et
non 1736.

### Formulation recommandée

> **« En 1730, le shogunat Tokugawa autorise à Dōjima un marché organisé
> du riz comprenant notamment un marché à terme ; il est considéré comme
> un précurseur des marchés à terme modernes. »**

**Source :** Japan Exchange Group (JPX).  
**Confiance : très élevée.**

------------------------------------------------------------------------

# 10:00–11:04 — Vitesse et transmission de l’information

## « La finance, c’est un jeu de vitesse »

**Verdict : 🟡**

Pertinent pour certains segments, notamment le trading haute fréquence,
mais faux comme description de toute la finance.

### Formulation recommandée

> **« Dans certains segments, notamment le trading haute fréquence, la
> vitesse d’exécution constitue un avantage concurrentiel majeur.
> D’autres stratégies ont des horizons de plusieurs mois ou plusieurs
> années. »**

------------------------------------------------------------------------

## Anecdote des 100 paysans

**Verdict : ⚪**

L’existence de systèmes de transmission rapide des prix du riz au Japon
est historiquement documentée.

En revanche, l’anecdote précise des **100 paysans espacés de 6 km
transmettant le cours en moins de 24 heures** n’a pas été suffisamment
établie par la source primaire consultée.

### Formulation recommandée

> **« Les marchés japonais du riz avaient développé des mécanismes
> sophistiqués de transmission rapide de l’information ; certaines
> anecdotes décrivent des systèmes destinés à accélérer cette
> transmission, mais les détails précis doivent être distingués des
> faits historiquement établis. »**

------------------------------------------------------------------------

La classification en :

- agriculture ;
- énergie ;
- métaux précieux ;

## « Les terres rares qui servent à faire des puces en silicium »

**Verdict : 🟠**

Confusion entre :

- silicium, matériau fondamental de nombreux semi-conducteurs ;

Les terres rares ne constituent pas simplement « le matériau des puces

:

**Verdict : 🟢**

Correct.

### Formulation recommandée

> »**

## « Tout le monde vit à crédit »

**Verdict : 🟡**

Formule rhétorique.

### Formulation recommandée

Le risque de crédit influence effectivement le spread, mais le taux

## Or mondial : « 80 milliards »

**Verdict : 🔴**

Le professeur se corrige oralement (« 80 trillions… pardon, 80 milliards

La valeur mondiale de l’or se situe dans un ordre de grandeur de

**Verdict : 🔴/🟠**

Le chiffre de 80 milliards est trop faible pour représenter l’ensemble
des billets et pièces en circulation dans le monde.

### Formulation recommandée

> **« La valeur des billets et pièces en circulation dans le monde se

## Capitalisation mondiale des actions : « 100 000 milliards »

**Verdict : 🟡**

L’ordre de grandeur était plausible à la date du graphique.

Mais une capitalisation doit être datée. SIFMA donne environ **157,8 T\$
en 2025** selon sa méthodologie.

### Formulation recommandée

> **« La capitalisation mondiale des actions était d’environ 100 T\$ à

------------------------------------------------------------------------

## Monnaie électronique

**Verdict : 🟢/🟡**

Il est correct qu’une grande partie de la monnaie moderne existe sous
forme électronique, notamment sous forme de dépôts bancaires.

Il faut cependant éviter de parler de « l’argent électronique » comme
d’un agrégat monétaire unique.

### Formulation recommandée

> **« Une grande partie de la monnaie moderne existe sous forme de

------------------------------------------------------------------------

## « La forme physique représente 10 % »

**Verdict : 🟠**

Cela dépend fortement de l’agrégat monétaire utilisé.

### Formulation recommandée

> **« La monnaie fiduciaire représente une fraction minoritaire de
> certains agrégats monétaires ; la proportion exacte dépend de
> l’agrégat retenu. »**

------------------------------------------------------------------------

## Dette mondiale : « 200 trillions »

**Verdict : 🟡**

L’ordre de grandeur dépend de la définition.

Pour les titres de dette à revenu fixe, SIFMA donne environ **160,7 T\$
en 2025**.

### Formulation recommandée

> **« Selon la définition retenue, les encours mondiaux de titres de

## Immobilier « aussi gros que la dette »

**Verdict : 🟡**

Cela peut être défendable selon le périmètre et la méthode de
valorisation, mais comparer un stock de patrimoine immobilier à un
encours de dette n’est pas une comparaison parfaitement homogène.

### Formulation recommandée

> **« L’immobilier mondial représente un patrimoine d’une ampleur
> comparable ou supérieure à certains grands marchés financiers, mais
> les méthodes de mesure ne sont pas directement comparables. »**

------------------------------------------------------------------------

# 22:02–34:49 — Produits dérivés

## « Une action représente quelque chose de physique »

**Verdict : 🟠**

Une action est avant tout un **droit juridique et financier**. Elle
n’est pas nécessairement un objet physique.

### Formulation recommandée

> **« Une action représente un droit sur une société ; une obligation
> représente une créance. Ces droits sont aujourd’hui essentiellement
> dématérialisés. »**

------------------------------------------------------------------------

## « Un produit dérivé, c’est juste un contrat entre deux personnes »

**Verdict : 🟡**

Bonne intuition mais trop restrictive.

### Formulation recommandée

> **« Un produit dérivé est un contrat financier dont la valeur dépend
> d’un actif, d’un taux, d’un indice ou d’une autre variable
> sous-jacente. »**

------------------------------------------------------------------------

## Exemple du pétrole : « contrat futur »

**Verdict : 🟠**

Le contrat personnalisé décrit oralement ressemble davantage à un
**forward** qu’à un **futures**.

Distinction essentielle :

- **forward** : contrat de gré à gré, généralement personnalisé ;
- **futures** : contrat standardisé négocié sur un marché organisé.

### Formulation recommandée

> **« Un forward est un contrat de gré à gré fixant aujourd’hui les
> conditions d’une livraison future ; un futures est un contrat
> standardisé négocié sur un marché organisé. »**

------------------------------------------------------------------------

## « Total est garanti qu’il vendra son pétrole à 100 dollars »

**Verdict : 🔴/🟠**

Trop simplifié.

Une couverture peut réduire ou fixer l’exposition au prix, mais le
résultat dépend du contrat, de la référence de prix, des échéances, des
coûts et des modalités de règlement.

### Formulation recommandée

> **« La couverture peut fixer ou limiter le prix effectif de vente ou
> d’achat, selon l’instrument utilisé, mais elle comporte un coût et des
> modalités précises. »**

------------------------------------------------------------------------

## « Les dérivés valent un quadrillion de dollars »

**Verdict : 🟠 MAJEUR**

Le problème principal est la confusion entre **notionnel** et **valeur
économique**.

Le BIS indiquait à fin juin 2025 environ :

- **846 T\$ de notionnel** pour les dérivés OTC ;
- **21,8 T\$ de valeur de marché brute**.

Le notionnel ne représente donc pas une richesse de 846 T\$.

### Formulation recommandée

> **« Le notionnel des dérivés OTC se chiffre en centaines de milliers
> de milliards de dollars, mais il ne faut pas le comparer directement à
> une capitalisation boursière : leur valeur de marché est beaucoup plus
> faible. »**

**Source :** BIS.  
**Confiance : très élevée.**

------------------------------------------------------------------------

## « OTC = parties qui gardent le truc secret »

**Verdict : 🟠**

OTC signifie **Over The Counter**, c’est-à-dire négocié de gré à gré,
hors marché organisé.

Cela ne signifie ni absence de réglementation ni secret absolu.

### Formulation recommandée

> **« Un dérivé OTC est négocié de gré à gré entre contreparties plutôt
> que sur un marché organisé ; ces transactions peuvent être soumises à
> des obligations de déclaration, de compensation et de collatéral selon
> les cas. »**

------------------------------------------------------------------------

## Lehman : effet de levier « x5, x10 sur le marché réel »

**Verdict : 🔴/🟠**

L’effet de levier n’est pas un multiplicateur universel appliqué au «

# 1:10:08–1:11:14 — Rendement, Buffett et taux de réussite

## « Les meilleurs traders gagnent 52 % du temps »

**Verdict : 🔴**

C’est une affirmation quantitative sans fondement général.

Le taux de trades gagnants ne suffit pas à mesurer la performance.

Exemple :

\[ 0{,}52-0{,}48=-0{,}44 \]

Une stratégie qui gagne 52 % de ses opérations peut donc perdre de
l’argent.

À l’inverse, une stratégie ayant moins de 50 % de trades gagnants peut
être rentable si ses gains moyens dépassent suffisamment ses pertes
moyennes.

### Formulation recommandée

> **« Le taux de réussite n’est pas une mesure suffisante de la
> performance d’un trader : il faut considérer l’espérance des gains et
> pertes, le risque, les coûts de transaction et le capital engagé. »**

------------------------------------------------------------------------

### Formulation recommandée

> **« Buffett souligne qu’un portefeuille diversifié d’actions peut être
> particulièrement pertinent pour un investisseur ayant un horizon de
> plusieurs décennies, mais il ne garantit ni une surperformance
> permanente ni un rendement annuel de 5 à 10 %. »**

# Ce que le professeur dit correctement

L’audit ne doit pas être lu comme une réfutation globale du cours.

Plusieurs idées centrales sont pédagogiquement solides :

### 1. Les trois fonctions de la monnaie

Unité de compte, moyen d’échange et réserve de valeur.

### 2. La confiance compte

La confiance dans les institutions, les contreparties et le système
monétaire est fondamentale.

### 3. Les entreprises utilisent les dérivés pour gérer leurs risques

L’exemple d’une compagnie aérienne exposée au prix du carburant est
pertinent.

### 4. La distinction investissement / spéculation est floue

Le professeur a raison de ne pas présenter cette frontière comme une
catégorie parfaitement objective.

### 5. Les acteurs financiers ont des fonctions différentes

Hedgers, investisseurs, spéculateurs, market makers et intermédiaires
peuvent être distingués fonctionnellement.

### 6. Les modèles ont des hypothèses

C’est un point particulièrement important.

Un modèle n’est pas « la réalité » : c’est une représentation simplifiée
de celle-ci.

### 7. La complexité n’est pas synonyme de qualité

Un modèle plus complexe peut être moins robuste ou moins utile si ses
hypothèses sont mauvaises ou s’il est mal adapté au problème.

### 8. Certains marchés sont effectivement extrêmement sensibles à la vitesse

C’est particulièrement vrai du trading haute fréquence.

# Principaux pièges pédagogiques identifiés

## 1. Transformer une intuition en loi générale

Exemple :

> « La confiance est le nerf de la guerre »

peut être une excellente intuition.

Mais :

> « Tout est basé sur la confiance »

devient une simplification excessive.

------------------------------------------------------------------------

## 2. Transformer une corrélation ou un mécanisme possible en causalité unique

Exemple :

> « Le pétrole monte parce qu’on ne fait pas confiance à une résolution
> rapide. »

Une formulation rigoureuse doit rappeler les autres déterminants.

------------------------------------------------------------------------

## 3. Oublier les unités

Le cas du Zimbabwe est l’exemple extrême.

Une erreur de trois ordres de grandeur change complètement l’information
transmise aux étudiants.

------------------------------------------------------------------------

## 4. Mélanger des grandeurs financières différentes

C’est particulièrement important pour les dérivés.

Il faut toujours distinguer :

- capitalisation ;
- encours ;
- notionnel ;
- valeur de marché ;
- valeur brute ;
- valeur nette ;
- flux ;
- stock.

Comparer ces grandeurs comme si elles représentaient toutes la même
chose conduit à des conclusions erronées.

------------------------------------------------------------------------

## 5. Utiliser des absolus

Les expressions suivantes devraient être utilisées avec beaucoup de
prudence :

- « toujours » ;
- « jamais » ;
- « tous » ;
- « personne » ;
- « le seul moyen » ;
- « tout le monde » ;
- « aucun autre domaine ».

Dans cette conférence, plusieurs des principales erreurs apparaissent
précisément après l’utilisation d’un de ces termes.

# Conclusion

Cette conférence constitue une **bonne introduction intuitive**, mais
elle ne devrait pas être utilisée seule comme support factuel de
référence.

La meilleure manière de l’enseigner serait de conserver :

- les exemples ;
- les analogies ;
- les anecdotes ;
- l’approche pratique ;
- la présentation des métiers ;
- la discussion sur les limites des modèles.

Il faudrait en revanche corriger ou nuancer systématiquement :

- les chiffres ;
- les dates ;
- les définitions ;
- les ordres de grandeur ;
- les relations causales ;
- les affirmations absolues ;
- les généralisations sur les acteurs ;
- les exemples probabilistes ;
- les affirmations sur les performances d’investissement.

Le résultat recherché n’est donc pas de rendre le cours plus académique
au détriment de sa pédagogie.

Il est de conserver son **intuition de praticien** tout en empêchant
l’étudiant de mémoriser comme des faits des formulations qui ne sont, au
mieux, que des raccourcis.

------------------------------------------------------------------------

## Verdict final

**Valeur pédagogique : élevée.**

**Robustesse factuelle : moyenne.**

**Robustesse des ordres de grandeur : moyenne à faible sur plusieurs
exemples.**

**Qualité des intuitions financières : généralement bonne.**

**Risque de mémorisation d’assertions fausses : non négligeable.**

La correction la plus importante n’est donc pas de remplacer le cours
par un cours théorique.

C’est de faire apparaître explicitement, à chaque étape, la différence
entre :

> **fait établi → simplification pédagogique → hypothèse → anecdote →
> spéculation.**

C’est cette distinction qui manque le plus souvent lorsque le discours
passe de l’intuition à l’affirmation catégorique.
