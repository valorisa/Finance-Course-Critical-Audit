# Finance Course Critical Audit

Audit factuel, critique et documenté du cours « Premier cours de finance à HEC Paris », enseigné par Olivier Bossard.

Ce dépôt analyse chronologiquement les principales affirmations formulées pendant le cours et confronte leur contenu aux sources disponibles, en privilégiant les sources primaires et institutionnelles : banques centrales, organismes internationaux, autorités de marché, institutions publiques, publications académiques et documents officiels.

L'objectif n'est pas de juger le professeur ou de produire une évaluation subjective du cours, mais d'identifier précisément :

- les affirmations factuellement correctes ;
- les affirmations globalement correctes mais nécessitant une précision ;
- les simplifications pédagogiques susceptibles d'induire en erreur ;
- les affirmations inexactes ou trop générales ;
- les anecdotes dont la vérifiabilité est insuffisante ;
- les chiffres nécessitant une date, une définition ou une méthodologie ;
- les distinctions conceptuelles importantes qui disparaissent dans la formulation orale.

Pour chaque point significatif, l'audit cherche à établir la formulation prononcée, son contexte, le verdict, les éléments vérifiables, le problème éventuel, la correction proposée et les sources permettant de contrôler cette correction.

Une attention particulière est portée aux sujets tels que la monnaie, l'or et la monnaie fiduciaire, l'inflation, les marchés financiers, les changes, les actions, les obligations, les produits dérivés, les hedge funds, le trading algorithmique, la vente à découvert, la dette souveraine, les crises financières, les modèles financiers et les performances historiques des marchés.

L'audit distingue explicitement les faits établis, les inférences, les simplifications pédagogiques, les hypothèses et les éléments non vérifiés. Il ne transforme pas une affirmation plausible en fait établi lorsqu'une source suffisamment solide n'a pas été trouvée.

Le dépôt constitue ainsi une documentation de vérification et de contextualisation du cours, destinée à permettre au lecteur de distinguer ce qui relève d'un fait financier établi, d'une approximation pédagogique, d'une interprétation ou d'une affirmation qui nécessite d'être corrigée.
